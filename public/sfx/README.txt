Voice reaction files used by the game (public/sfx/):

  MALE
  male_mm_hmm.mp3   → hmm, hm, mm, agree   (warm agreement)
  male_uhh.mp3      → uhh, oh              (surprised "huh?")
  man_laugh.mp3     → heh, chuckle, laugh  (tease / amused)
  man_hug.mp3       → hug                  (his hug reaction)

  FEMALE
  girl-giggle.mp3   → giggle, hehe, smile, softlaugh, girllaugh
  girl_scared.mp3   → shy                  (nervous / startled)
  girl_sigh.mp3     → sigh, breath         (content / soft breath)
  female_mm.mp3     → female_mm            (rare — only special soft moments)
  girl_hugging.wav  → hug_girl             (her hug reaction)

  ACTIONS / SPECIAL
  kiss.mp3          → kiss
  slap.wav          → slap
  moan.mp3          → moan (intimate)
  sleeping.mp3      → sleeping

Volumes are set in src/audio/audio.ts → SFX_FILES
